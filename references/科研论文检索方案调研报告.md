## 一、调研概述

### 1.1 背景

deep-research-ultra v4.0 已集成 arxiv-mcp-server、paper-search-mcp-nodejs、Semantic Scholar MCP、Scientific-Papers-MCP 等学术检索能力。为支撑 v5.0 的「学术级深度调研」目标，需要系统评估 2025-2026 年科研论文检索生态，识别可补充的能力缺口：

- **引用图谱与影响力分析**：当前仅有 arxiv-mcp-server 的 `citation_graph`（依赖 Semantic Scholar）
- **开放获取全文**：当前依赖 paper-search-mcp 的 `download_with_fallback`，未覆盖 Unpaywall 直连
- **中文文献**：当前完全缺失，无任何中文数据库接入
- **论文关系可视化**：无 Connected Papers / Inciteful 类工具
- **RAG 级语义检索**：sciverse skill 已存在但未纳入主调研流水线

### 1.2 关键发现速览

- **paper-search-mcp**（openags）已成为 2025-2026 学术 MCP 事实标准，覆盖 22+ 平台，能力矩阵最完整
- **arxiv-mcp-server**（blazickjp）v0.6.2 工具数增至 14，新增 LaTeX 分节检索、BibTeX 导出、citation_graph
- **OpenAlex API** 数据量从 240M 增至 474M 作品，免费额度 10 万次/天，无需 Key，是最大免费学术数据源
- **Semantic Scholar API** 200M+ 论文，独有「引用意图（intents）」字段，是 AI 引用上下文分析首选
- **中文数据库**全部需要爬虫或付费 API，无官方免费开放接口

### 2.1 arxiv-mcp-server（blazickjp）

| 维度 | 详情 |
|------|------|
| **仓库** | https://github.com/blazickjp/arxiv-mcp-server |
| **最新版本** | v0.6.2（2026-07-29） |
| **数据覆盖** | arXiv 全量 2.4M+ 论文（物理/数学/计算机科学/统计学/定量生物学/定量金融/经济学/电气工程） |
| **工具数** | 14 个 |
| **免费额度** | 完全免费，无 Key |
| **速率限制** | 受 arXiv API 上游限制（建议 1 请求/3 秒） |
| **国内可用** | ✅ arXiv.org 国内可直连 |
| **集成难度** | 低（`uvx arxiv-mcp-server` 一键启动） |

**工具清单（14 个）：**
1. `search_papers` — 按查询/分类/日期/排序搜索
2. `get_abstract` — 按 arXiv ID 取元数据+摘要
3. `download_paper` — 下载并转为本地 Markdown（HTML 优先，PDF 兜底）
4. `list_papers` — 列出本地已下载论文
5. `read_paper` — 读取本地论文内容（支持分页）
6. `get_paper_latex` — 取作者提交的原始 LaTeX
7. `list_paper_latex_sections` — LaTeX 分节大纲
8. `get_paper_latex_section` — 读取单节 LaTeX
9. `citation_graph` — 引用图谱（**调用 Semantic Scholar API**）
10. `export_citations` — 导出 BibTeX
11. `watch_topic` — 保存 arXiv 主题订阅
12. `check_alerts` — 检查订阅的新论文
13. `semantic_search` — 语义搜索本地论文（需 `[pro]` 扩展）
14. `reindex` — 重建本地语义索引（需 `[pro]` 扩展）

**独有优势：**
- 唯一支持原始 LaTeX 分节检索的 MCP
- 内置订阅告警机制（watch_topic + check_alerts）
- 本地语义索引（pro 扩展），离线 RAG 可行
- citation_graph 直接复用 Semantic Scholar，无需另装 MCP

**局限：**
- 仅 arXiv 单源，不含正式发表的期刊论文
- pro 语义搜索需额外安装 `[pdf]` / `[pro]` 扩展

**客户端支持：** Claude Code、OpenAI Codex、Kiro、VS Code、Claude Desktop（含 .mcpb bundle）

| IEEE Xplore 🔑 | 🚧 骨架 | 🚧 骨架 | 🚧 骨架 | 需 `PAPER_SEARCH_MCP_IEEE_API_KEY` |
| ACM DL 🔑 | 🚧 骨架 | 🚧 骨架 | 🚧 骨架 | 需 `PAPER_SEARCH_MCP_ACM_API_KEY` |

**架构亮点（两层设计）：**
- **Layer 1（统一工具）**：`search_papers` 多源并发搜索 + 去重；`download_with_fallback` 按 OA 链路顺序降级
- **Layer 2（平台连接器）**：模块化，每个平台独立实现，易于扩展

**OA-First 降级链：**
```
源生下载链接 → OpenAIRE/CORE/Europe PMC/PMC 发现 → Unpaywall DOI 解析 → (可选) Sci-Hub
```

**Key 要求：**
- `PAPER_SEARCH_MCP_UNPAYWALL_EMAIL`：**必需**（否则 Unpaywall 禁用）
- `PAPER_SEARCH_MCP_CORE_API_KEY`：推荐（免费，提升稳定性）
- `PAPER_SEARCH_MCP_SEMANTIC_SCHOLAR_API_KEY`：可选（提升配额）
- `PAPER_SEARCH_MCP_DOAJ_API_KEY`：可选（提升小时配额）
- `PAPER_SEARCH_MCP_ZENODO_ACCESS_TOKEN`：可选（私有记录）
- `PAPER_SEARCH_MCP_IEEE_API_KEY` / `PAPER_SEARCH_MCP_ACM_API_KEY`：激活付费平台

**反爬能力：**
- Google Scholar：支持配置代理 URL 绕过 CAPTCHA
- Semantic Scholar：Key 被拒(403) 自动降级为无 Key 重试
- CORE：指数退避 + 401/403 降级为无 Key
- OpenAIRE：3 次递进重试（plain session → XML Accept → raw requests + Mozilla UA）
- SSRN：双端点尝试，失败返回明确信息

**nodejs 版本：** `paper-search-mcp-nodejs`（npx 一键启动，无需 Python 环境）

**独有优势：**
- 平台覆盖最广（22+），是学术 MCP 事实标准
- Free-First 设计，开源优先
- 双形态：MCP server + Claude Code skill
- IEEE/ACM 骨架已就绪，配置 Key 即激活

**局限：**
- Google Scholar 反爬严重，实际可用性低
- IEEE/ACM 仅骨架，下载/阅读未实现
- 部分平台（CiteSeerX/BASE/SSRN）稳定性差

**局限：**

### 3.2 Semantic Scholar API

| 维度 | 详情 |
|------|------|
| **官网** | https://www.semanticscholar.org/ |
| **API 文档** | https://api.semanticscholar.org/api-docs/ |
| **数据量** | **200M+ 论文** |
| **免费额度** | 无 Key：约 100 req/5min；有 Key：更高 |
| **Key 要求** | 可选，免费申请 |
| **国内可用** | ✅ 直连 |
| **鉴权** | `x-api-key` header |

**独有能力（差异化）：**
- **citation intents**：引用意图（methodology/background/result）
- **influential citations**：影响力引用筛选
- **TLDR**：AI 一句话摘要

**局限：**
- 需 `SCIVERSE_API_TOKEN`（非完全免费，需注册）
- 数据源为专有 Sciverse.space，非开放 API
- 无引用图谱/影响力分析

**集成建议：** 作为 RAG 语义检索层纳入 deep-research-ultra 学术流水线，与 MCP 元数据搜索互补。

## 九、风险与注意事项

### 9.1 合规风险

| 风险 | 等级 | 说明 |
|------|------|------|
| 知网/万方爬虫 | 🔴 高 | 法律维权先例，违反 ToS |
| Sci-Hub | 🔴 高 | 版权违法，仅作可选兜底 |
| Google Scholar 爬虫 | 🟡 中 | 违反 ToS，但无诉讼先例 |
| Unpaywall | 🟢 低 | 仅索引合法 OA |
| OpenAlex/S2/Crossref | 🟢 低 | 明确免费开放 |

### 9.2 稳定性风险

| 风险 | 缓解措施 |
|------|----------|
| Google Scholar CAPTCHA | 仅作 fallback，需代理 |
| Semantic Scholar 429 | 配置 Key + 指数退避 |
| CiteSeerX/BASE/SSRN 不稳 | paper-search-mcp 已优雅降级 |
| arXiv API 限速 | 1 req/3s，串行化 |
| 中文数据库无 API | 元数据用 OpenAlex，全文走机构 |

### 9.3 数据质量注意

- OpenAlex/Semantic Scholar 元数据可能有错（自动抽取）
- Crossref DOI 元数据最权威但仅元数据
- arXiv 预印本可能未正式发表，版本可能更新
- Unpaywall OA 链接可能失效（仓库下架）
