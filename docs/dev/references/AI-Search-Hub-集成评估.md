## 一、它是什么

聚合 **8 个大厂 AI 平台原生搜索**的开源 skill：Gemini / Grok / 豆包 / **元宝** /
LongCat / 通义千问 / MiniMax / Kimi。核心主张："给一个问题让大厂替你搜"——
借平台已连接的数据世界（元宝→微信公众号、豆包→抖音/头条、LongCat→美团/点评、
Grok→X/Twitter），拿平时最难触达的围墙数据，再统一回收给 Agent。

**机制（关键）**：Playwright + CDP（Chrome 调试口 9222）驱动**真浏览器**——
`run_web_chat.py` 从用户本地浏览器数据克隆一个隔离调试 profile（**含登录态**），
打开目标站点、把 prompt 打进聊天框、等待 AI 回复、回收结果；检测到未登录则
**等待用户手动登录后继续**。依赖 `pip install playwright` + chromium。

**维护状态**：最后一次实质提交 **2026-04-27**（README 更新），Kimi 支持合并于
03-31——距今约 6 个月无提交。浏览器自动化项目对着快速迭代的 AI 聊天 UI，
6 个月不更新意味着选择器碎裂风险高（对照本项目自身经验：SERP 引擎月级别改版）。

## 二、与用户红线的冲突点（决定性约束）

用户红线（2026-10-04，Agent-Reach 接入时确立）：**不接受任何登录账号封号风险
——凡需 Cookie/浏览器登录态的通道一律不装、不配、不引 Cookie**。理由：平台会
检测非人类操作并封号（Agent-Reach 官方文档自认，本项目 SKILL.md 已成文）。

AI-Search-Hub 的全部 8 个平台**均属登录态通道**，且比 Cookie 导出更进一步：
直接**自动化驱动登录会话**（往聊天框打字）。封号风险类别与 Agent-Reach 登录
通道相同甚至更高频（每次调研多轮打字交互 vs 一次性 API 调用）。

## 三、真正有价值的可借鉴资产（零风险部分）

**ROUTING.md 的"问题→数据世界亲和"框架**：先按语言/地域分流（国际/国内/混合），
再按**母公司生态**选平台（微信公众号→腾讯系→元宝；抖音头条→字节系→豆包；
本地生活→美团系→LongCat）。这个映射本身是路由智慧，不依赖浏览器自动化：

| 数据需求 | AI-Search-Hub 路由 | 我们的匿名现状 |
|---|---|---|
| 微信公众号 | 元宝 | **已有** sogou-weixin（匿名） |
| 抖音/头条舆情 | 豆包 | 无匿名通道（缺口） |
| 微博 | （多平台） | 无（缺口） |
| 大众点评/本地生活 | LongCat | 无（缺口） |
| X/Twitter 实时 | Grok | 无（缺口，且 X 需登录） |

## 四、三条集成路径

| 路径 | 内容 | 风险 | 收益 |
|---|---|---|---|
| **A. 借鉴不接入**（推荐） | 把 ROUTING.md 的生态映射吸收进本项目智能路由与报告类型学（references/report-types.md 商业调研行的源建议）；本项目文档归档本文 | 零 | 路由智慧免费；不新增任何登录面 |
| B. 用户显式授权通道 | 装为兄弟 skill（playwright 进独立 venv），本项目 SKILL.md 红线节加一条"用户显式要求时可用的 🤖 档通道，**必须专用小号**"；子 Agent 调 `run_web_chat.py --site yuanbao` | 与 Agent-Reach 登录通道同级；叠加 6 个月未维护的碎裂风险 | 公众号/抖音/点评深挖能力（AI 已清洗整理过的） |
| C. 先装不用，只验证可装性 | 装 venv + `--help` 冒烟，不登录不触站 | 近零（不碰站点） | 只验证安装面，验证不了有用性（有用性必须登录） |

## 五、推荐

**先 A，B 留作用户显式开通**：

1. **A 立即做**：`references/report-types.md` 商业调研/社区口碑行补"数据世界亲和"
   提示（公众号→sogou-weixin；抖音/微博/点评为已知缺口，需要时评估登录通道）；
   本文归档 `docs/dev/references/`。
2. **B 不主动做**：与用户红线直接冲突（自动化驱动登录会话），且仓库 6 个月未维护，
   碎裂概率高。用户未来显式要求时按 Agent-Reach 同款流程走：专用小号 +
   Phase 0 停等 + 逐平台开通，并在红线文档登记。
3. **缺口记录**：抖音/微博/点评的匿名通道是真实能力缺口，但目前没有免登录的
   合规入口；如未来出现（平台开放 API / Agent-Reach 免登录档扩展），优先接入。
