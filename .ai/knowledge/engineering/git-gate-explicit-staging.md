# Mimosa git 门禁：显式路径暂存 + 非确定性重试

**生效**: 2026-10-04
**记录**: 2026-10-04
**置信度**: [F]（多次实跑验证，doc-pin 于工作区 .learnings/ERR-20261004-001）
**Related**: zcode-agents-junction（同环境事实）

## 事实

工作区装 Mimosa 安全钩子后，`git add -A && git commit` 会被全树暂存扫描拦截——
拿 `opensource-reference/` 第三方项目测试代码的存量误报（如 spec-kit 的路径穿越
测试夹具）报"1274 个高危"强制阻断，且被拦时**整个 Bash 调用（含前置测试命令）
都不执行**。

显式路径 `git add <paths> && git commit` 正常通过，但**非确定性**：同一命令
v6.53.0/v6.53.1/v6.53.2 各被拦一次，原样重试即过（扫描与文件写入存在时序竞态）。

**Related**: 本工作区已做过 deep 全树扫描并封印（scanId
`scan-2026-10-04T01-58-49.571Z-9065df4e8422`，seal `sha256:3486…0770`），849 条
发现全在第三方克隆与既有脚本，super-memory 与当次改动 0 发现——再遇"覆盖不完整"
提示先查封印，不要重复全树排查。

## How to apply

- 提交一律显式列路径，不用 `git add -A`；
- 被拦时原样重试 1-2 次，不需要改提交内容；
- 写带网络/子进程的脚本时按其预写扫描建议改（域名白名单、正则全匹配、
  `shell=False`），不要绕。
