## 二、arXiv 全文下载方案

### 2.1 arXiv API 官方端点（权威来源）

**基础 URL**：`http://export.arxiv.org/api/query`

**查询参数**（官方 user-manual 原文）：

| 参数 | 类型 | 默认 | 必需 | 说明 |
|------|------|------|------|------|
| `search_query` | string | None | 否 | 查询字符串，支持 `all:`/`ti:`/`au:`/`abs:`/`cat:` 前缀 |
| `id_list` | string | None | 否 | 逗号分隔的 arXiv ID 列表 |
| `start` | int | 0 | 否 | 0-based 起始索引 |
| `max_results` | int | 10 | 否 | 返回数；**单次≤30000，单批建议≤2000** |
| `sortBy` | - | relevance | 否 | `relevance`/`lastUpdatedDate`/`submittedDate` |
| `sortOrder` | - | descending | 否 | `ascending`/`descending` |

**search_query 与 id_list 逻辑**：
- 仅 search_query：返回匹配文章
- 仅 id_list：返回 id_list 中的文章
- 两者皆有：返回 id_list 中且匹配 search_query 的文章（过滤模式）

**速率限制（官方原文）**：
> "we encourage you to play nice and incorporate a 3 second delay in your code"

**分页限制（官方原文）**：
> "the maximum number of results returned from a single call (`max_results`) is limited to 30000 in slices of at most 2000 at a time"
> "A request with `max_results` >30,000 will result in an HTTP 400 error code"

### 2.2 PDF 与 LaTeX 源码下载端点

arXiv API 的 Atom feed 中，每个 `<entry>` 包含 `<link>` 元素，其中：

| 链接类型 | URL 模式 | 用途 |
|---------|---------|------|
| 摘要页 | `https://arxiv.org/abs/{id}` | 元数据 + 摘要 |
| PDF | `https://arxiv.org/pdf/{id}.pdf` | 全文 PDF（**v5.1+ 支持 HTML 优先**） |
| HTML（新） | `https://arxiv.org/html/{id}` | arXiv HTML 全文（2023+ 论文） |
| LaTeX 源码 | `https://arxiv.org/e-print/{id}` | 作者提交的原始 LaTeX 压缩包 |

**arXiv HTML 全文**：arXiv 2023 年起推出 HTML 版本（ar5iv 衍生），arxiv-mcp-server v0.6.2 的 `download_paper` 采用 **HTML 优先、PDF 兜底** 策略，转换质量优于纯 PDF 解析。

### 2.3 批量下载方案（官方推荐顺序）

arXiv 官方 bulk_data 文档明确列出全文获取的 4 种途径，按推荐度排序：

| 方式 | 适用场景 | 端点 | 限制 |
|------|---------|------|------|
| **AWS S3** | 全量/大批量 | `s3://arxiv`（需请求访问） | 需 AWS 账号，PDF + LaTeX 源码 |
| **Kaggle Dataset** | 全量 PDF | `kaggle.com/Cornell-University/arxiv` | Kaggle 账号 |
| **OAI-PMH 爬取** | 增量/子集 | `https://export.arxiv.org/oai2` | 元数据为主，全文需另下载 |
| **API 逐篇下载** | 小批量 | `https://arxiv.org/pdf/{id}` | 3 秒延迟，单次≤30000 |

**元数据批量**：
- arXiv API（上述 query 端点）
- DataCite API（`provider-id=arxiv`）
- Kaggle 元数据集

**官方声明**：
> "At this time, we do not require that commercial projects sign an MOU. We do encourage anyone who benefits financially from arXiv consider becoming an affiliate or a sponsor; however, doing so is completely optional."

### 2.4 arxiv-mcp-server v0.6.2 封装能力（已就绪）

**版本**：v0.6.2（2026-07-29 发布）
**License**：Apache 2.0
**工具数**：14

arXiv 全文相关工具：

| 工具 | 输入 | 输出 | 实现 |
|------|------|------|------|
| `download_paper` | `paper_id`, `max_chars` | 本地 Markdown（HTML 优先，PDF 兜底用 `[pdf]` extra） | arXiv HTML / pymupdf4llm |

### 2.5 自封装 ArxivFulltextEngine 伪代码（fallback 方案）

```python
import urllib.parse
import time
import re
from typing import Dict, List, Optional
import xml.etree.ElementTree as ET

from .base import SearchEngine, SearchResult, EngineMetadata
from .fallback import _http_get

class ArxivFulltextEngine(SearchEngine):
    """
    arXiv 全文下载引擎（直连 API，作为 arxiv-mcp-server 的 fallback）

    能力：search, academic, fulltext, latex
    数据量：2.4M+ 预印本
    API Key：无需
    国内可用：✅
    速率限制：3 秒/请求（官方建议）

    API 文档：https://info.arxiv.org/help/api/user-manual.html
    """

    SEARCH_URL = "http://export.arxiv.org/api/query"
    PDF_URL_TEMPLATE = "https://arxiv.org/pdf/{paper_id}.pdf"
    HTML_URL_TEMPLATE = "https://arxiv.org/html/{paper_id}"
    LATEX_URL_TEMPLATE = "https://arxiv.org/e-print/{paper_id}"
    ATOM_NS = "{http://www.w3.org/2005/Atom}"
    ARXIV_NS = "{http://arxiv.org/schemas/atom}"

    # 上次请求时间戳（用于速率限制）
    _last_request_time: float = 0.0

    @property
    def metadata(self) -> EngineMetadata:
        return EngineMetadata(
            name="arxiv-fulltext",
            layer=1,
            description="arXiv 全文下载（PDF/HTML/LaTeX，2.4M+ 预印本）",
            requires_config=False,
            config_keys=[],
            is_async_supported=False,
            is_china_friendly=True,
            priority=44,  # 略高于 OpenAlex（45），全文优先
            capabilities=["search", "academic", "fulltext", "latex"],
        )

    def _rate_limit(self) -> None:
        """官方建议 3 秒延迟"""
        elapsed = time.time() - self._last_request_time
        if elapsed < 3.0:
            time.sleep(3.0 - elapsed)
        self._last_request_time = time.time()

    def is_available(self) -> bool:
        try:
            params = urllib.parse.urlencode({'search_query': 'all:test', 'max_results': 1})
            url = f"{self.SEARCH_URL}?{params}"
            self._rate_limit()
            raw = _http_get(url, timeout=10, max_retries=1)
            return raw is not None
        except Exception:
            return False

    def search(self, query: str, max_results: int = 10, **kwargs) -> Optional[List[SearchResult]]:
        """
        arXiv 搜索（返回元数据 + PDF/HTML/LaTeX URL）

        Args:
            query: 搜索关键词（支持 'cat:cs.LG' 等前缀）
            max_results: 最大结果数（单批≤2000，单次≤30000）
            **kwargs:
                categories: arXiv 分类列表（如 ['cs.LG', 'cs.AI']）
                sort_by: 'relevance'/'lastUpdatedDate'/'submittedDate'
                sort_order: 'ascending'/'descending'
                id_list: 按 ID 查询（逗号分隔）
                proxy: 代理地址
        """
        # 限制单批
        per_page = max(1, min(int(max_results), 2000))
        params_dict: Dict[str, str] = {
            'max_results': str(per_page),
        }

        # 构造 search_query
        search_query = query
        categories = kwargs.get('categories')
        if categories:
            cat_query = ' OR '.join(f'cat:{c}' for c in categories)
            search_query = f'({search_query}) AND ({cat_query})' if search_query else cat_query
        if search_query:
            params_dict['search_query'] = search_query
        if kwargs.get('id_list'):
            params_dict['id_list'] = str(kwargs['id_list'])
        if kwargs.get('sort_by'):
            params_dict['sortBy'] = str(kwargs['sort_by'])
        if kwargs.get('sort_order'):
            params_dict['sortOrder'] = str(kwargs['sort_order'])

        params = urllib.parse.urlencode(params_dict, safe='():')
        url = f"{self.SEARCH_URL}?{params}"

        self._rate_limit()
        raw = _http_get(url, timeout=30, proxy=kwargs.get('proxy'))
        if not raw:
            return None

        # 解析 Atom XML
        try:
            text = raw.decode('utf-8') if isinstance(raw, bytes) else raw
            root = ET.fromstring(text)
        except ET.ParseError:
            return None

        results: List[SearchResult] = []
        for entry in root.findall(f'{self.ATOM_NS}entry'):
            paper_id = ''
            title = ''
            summary = ''
            authors: List[str] = []
            pdf_url = ''
            html_url = ''
            published = ''
            updated = ''
            doi = ''
            categories: List[str] = []
            comment = ''

            id_elem = entry.find(f'{self.ATOM_NS}id')
            if id_elem is not None and id_elem.text:
                # https://arxiv.org/abs/2404.19756v1 → 2404.19756
                paper_id = id_elem.text.strip().split('/abs/')[-1]
                if 'v' in paper_id:
                    paper_id = paper_id.split('v')[0]

            title_elem = entry.find(f'{self.ATOM_NS}title')
            if title_elem is not None and title_elem.text:
                title = ' '.join(title_elem.text.split())  # 折叠空白

            summary_elem = entry.find(f'{self.ATOM_NS}summary')
            if summary_elem is not None and summary_elem.text:
                summary = ' '.join(summary_elem.text.split())

            for author in entry.findall(f'{self.ATOM_NS}author'):
                name_elem = author.find(f'{self.ATOM_NS}name')
                if name_elem is not None and name_elem.text:
                    authors.append(name_elem.text.strip())

            for link in entry.findall(f'{self.ATOM_NS}link'):
                rel = link.get('rel', '')
                title_attr = link.get('title', '')
                if rel == 'related' and title_attr == 'pdf':
                    pdf_url = link.get('href', '')
                elif rel == 'alternate':
                    html_url = link.get('href', '')

            # arXiv 扩展元素
            doi_elem = entry.find(f'{self.ARXIV_NS}doi')
            if doi_elem is not None and doi_elem.text:
                doi = doi_elem.text.strip()

            comment_elem = entry.find(f'{self.ARXIV_NS}comment')
            if comment_elem is not None and comment_elem.text:
                comment = comment_elem.text.strip()

            for cat in entry.findall(f'{self.ARXIV_NS}primary_category'):
                categories.append(cat.get('term', ''))

            published_elem = entry.find(f'{self.ATOM_NS}published')
            if published_elem is not None and published_elem.text:
                published = published_elem.text[:10]  # YYYY-MM-DD

            # 构建 PDF/HTML/LaTeX URL（即使 API 未返回，也按模板生成）
            if not pdf_url:
                pdf_url = self.PDF_URL_TEMPLATE.format(paper_id=paper_id)
            if not html_url:
                html_url = self.HTML_URL_TEMPLATE.format(paper_id=paper_id)
            latex_url = self.LATEX_URL_TEMPLATE.format(paper_id=paper_id)

            # 构建内容片段
            content_parts = []
            if summary:
                content_parts.append(summary)
            if comment:
                content_parts.append(f"[Comment] {comment}")
            if categories:
                content_parts.append(f"[Categories] {', '.join(categories)}")
            if doi:
                content_parts.append(f"[DOI] {doi}")
            content_parts.append(f"[PDF] {pdf_url}")
            content_parts.append(f"[HTML] {html_url}")
            content_parts.append(f"[LaTeX] {latex_url}")
            content = '\n'.join(content_parts)

            author_str = '; '.join(authors[:10])
            if len(authors) > 10:
                author_str += f' et al. ({len(authors)} authors)'

            results.append(SearchResult(
                title=title,
                url=html_url or f"https://arxiv.org/abs/{paper_id}",
                content=content,
                source='arxiv',
                score=0.5,  # arXiv 无引用计数，给中性分
                published_date=published,
                author=author_str,
                engine='arxiv-fulltext',
                raw={
                    'paper_id': paper_id,
                    'pdf_url': pdf_url,
                    'html_url': html_url,
                    'latex_url': latex_url,
                    'doi': doi,
                    'categories': categories,
                    'comment': comment,
                },
            ))

        return results if results else None

    def download_pdf(self, paper_id: str, save_path: str, **kwargs) -> Optional[str]:
        """
        下载 arXiv PDF 到本地

        Args:
            paper_id: arXiv ID（如 '2404.19756'，可含版本 'v1'）
            save_path: 本地保存路径
        Returns:
            保存的文件路径，失败返回 None
        """
        # 规范化 paper_id（去掉 v 后缀）
        clean_id = paper_id.split('v')[0] if 'v' in paper_id else paper_id
        url = self.PDF_URL_TEMPLATE.format(paper_id=clean_id)
        self._rate_limit()
        raw = _http_get(url, timeout=60, proxy=kwargs.get('proxy'))
        if not raw:
            return None
        try:
            with open(save_path, 'wb') as f:
                f.write(raw)
            return save_path
        except IOError:
            return None

    def fetch_latex(self, paper_id: str, **kwargs) -> Optional[Dict]:
        """
        获取 arXiv LaTeX 源码（tar.gz 压缩包）

        Args:
            paper_id: arXiv ID
        Returns:
            {'tar_gz': bytes, 'paper_id': str} 或 None
        """
        clean_id = paper_id.split('v')[0] if 'v' in paper_id else paper_id
        url = self.LATEX_URL_TEMPLATE.format(paper_id=clean_id)
        self._rate_limit()
        raw = _http_get(url, timeout=60, proxy=kwargs.get('proxy'))
        if not raw:
            return None
        return {'tar_gz': raw, 'paper_id': clean_id}
```

**关键实现要点**：
1. **速率限制**：`_rate_limit()` 强制 3 秒间隔（类变量记录上次请求时间）
2. **XML 解析**：使用 `xml.etree.ElementTree`，注意 Atom + arXiv 双命名空间
3. **URL 模板**：即使 API link 未返回 PDF/HTML，也按模板生成（arXiv URL 规律稳定）
4. **paper_id 规范化**：`2404.19756v1` → `2404.19756`（PDF URL 不含版本）
5. **LaTeX 源码**：返回 tar.gz bytes，需调用方解压

## 三、Unpaywall 开放获取方案

### 3.1 API 端点（官方文档原文）

**基础 URL**：`https://api.unpaywall.org/v2`

**鉴权方式**：URL 末尾必带 `email` 参数
```
api.unpaywall.org/my/request?email=YOUR_EMAIL
```

**速率限制**：100,000 calls/day（官方明确）
> "Please limit use to 100,000 calls per day. If you need faster access, you'll be better served by downloading the entire database snapshot for local access."

**版本**：Version 2（唯一支持版本）

### 3.2 端点详情

#### 端点 1：DOI 查询（核心）

```
GET /v2/:doi?email=YOUR_EMAIL
```

**示例**：`https://api.unpaywall.org/v2/10.1038/nature12373?email=YOUR_EMAIL`

**返回**：[DOI Object](https://unpaywall.org/data-format#doi-object)

#### 端点 2：标题搜索

```
GET /v2/search?query=:your_query[&is_oa=boolean][&page=integer]&email=YOUR_EMAIL
```

**参数**：
- `query`：搜索文本，空格分隔默认 AND；支持 `"引号短语"`、`OR`、`-` 取反
- `is_oa`（可选）：`true` 仅返回 OA 文章，`false` 仅返回非 OA
- `page`（可选）：分页，每页 50 条
- `email`：**必需**

**示例**：`https://api.unpaywall.org/v2/search?query=cell%20thermometry&is_oa=true&email=YOUR_EMAIL`

**返回**：数组，每项含 `response`（完整 DOI Object）+ `score` + `snippet`

### 3.3 DOI Object 关键字段（官方 schema）

| 字段 | 类型 | 说明 |
|------|------|------|
| `doi` | string | 小写 DOI |
| `doi_url` | string | `https://doi.org/` + doi |
| `title` | string\|null | 标题 |
| `genre` | string\|null | Crossref 类型（journal-article 最常见） |
| `is_oa` | boolean | 是否有 OA 副本（= best_oa_location 非 null） |
| `oa_status` | string | `gold`/`hybrid`/`bronze`/`green`/`closed` |
| `journal_is_oa` | boolean | 是否完全 OA 期刊 |
| `journal_is_in_doaj` | boolean | 是否 DOAJ 索引 |
| `journal_issns` | string\|null | ISSN（多值逗号分隔） |
| `journal_name` | string\|null | 期刊名 |
| `year` | int\|null | 出版年份 |
| `published_date` | string\|null | ISO8601 日期 |
| `publisher` | string\|null | 出版社 |
| `best_oa_location` | Object\|null | **最佳 OA 位置**（算法见下） |
| `first_oa_location` | Object\|null | 最早 OA 位置 |
| `oa_locations` | List | 所有 OA 位置列表 |
| `oa_locations_embargoed` | List | 未来可用的禁运 OA 位置（beta） |
| `z_authors` | List\|null | 作者列表（含 raw_author_name/affiliation） |

### 3.4 OA Location Object 字段

| 字段 | 说明 |
|------|------|
| `host_type` | `publisher`（出版社）或 `repository`（仓库，含预印本服务器） |
| `is_best` | 是否为 best_oa_location |
| `url` | url_for_pdf 优先，否则 landing page |
| `url_for_pdf` | **PDF 直链**（核心字段） |
| `url_for_landing_page` | 落地页 URL（host_type=publisher 时通常含 HTML 全文） |
| `version` | `submittedVersion`/`acceptedVersion`/`publishedVersion` |
| `license` | 许可证（如 `cc-by-nc`、`implied-oa`、`null`） |
| `oa_date` | 此位置首次可用日期 |

### 3.5 best_oa_location 选择算法（官方原文）

> "The 'best' location is determined using an algorithm that prioritizes publisher-hosted content first (eg Hybrid or Gold), then prioritizes versions closer to the version of record (`PublishedVersion` over `AcceptedVersion`), then more authoritative repositories (PubMed Central over CiteSeerX)."

**优先级顺序**：
1. **host_type**：publisher > repository
2. **version**：publishedVersion > acceptedVersion > submittedVersion
3. **仓库权威性**：PMC > CiteSeerX（同 version 时）

### 3.6 OA 状态分类

| oa_status | 含义 | 典型场景 |
|-----------|------|---------|
| `gold` | 完全 OA 期刊（DOAJ 索引） | PLOS、Nature Communications |
| `hybrid` | 订阅期刊中的 OA 文章（付费 APC） | Elsevier 单篇 OA |
| `bronze` | 出版社免费但无明确许可 | 临时免费、旧文章 |
| `green` | 仓库 OA（PMC/arXiv/机构库） | 作者自存档 |
| `closed` | 无 OA 副本 | 仅订阅可得 |

### 3.7 自封装 UnpaywallEngine 伪代码

```python
import urllib.parse
import os
from typing import Dict, List, Optional

from .base import SearchEngine, SearchResult, EngineMetadata
from .fallback import _http_get


class UnpaywallEngine(SearchEngine):
    """
    Unpaywall 开放获取引擎（DOI → 合法 OA PDF）

    能力：search, academic, fulltext, oa
    数据量：1000 万+ OA 文章索引
    API Key：无需（**必需 email 参数**）
    国内可用：✅
    速率限制：100,000 calls/day

    API 文档：https://unpaywall.org/products/api
    """

    BASE_URL = "https://api.unpaywall.org/v2"

    @property
    def metadata(self) -> EngineMetadata:
        return EngineMetadata(
            name="unpaywall",
            layer=1,
            description="Unpaywall 开放获取（DOI→OA PDF，1000万+ OA 文章）",
            requires_config=False,  # email 非 Key，但必填
            config_keys=["UNPAYWALL_EMAIL"],
            is_async_supported=False,
            is_china_friendly=True,
            priority=43,  # 全文获取优先级最高
            capabilities=["search", "academic", "fulltext", "oa"],
        )

    def _get_email(self, **kwargs) -> Optional[str]:
        """获取 email 参数（必需）"""
        email = kwargs.get('email') or os.environ.get('UNPAYWALL_EMAIL', '')
        if not email:
            # 降级：使用默认 email（仅测试用，生产环境必须配置）
            email = 'research@deep-research-ultra.local'
        return email

    def is_available(self) -> bool:
        try:
            email = os.environ.get('UNPAYWALL_EMAIL', 'test@example.com')
            url = f"{self.BASE_URL}/10.1038/nature12373?email={urllib.parse.quote(email)}"
            raw = _http_get(url, timeout=10, max_retries=1)
            return raw is not None
        except Exception:
            return False

    def search_by_doi(self, doi: str, **kwargs) -> Optional[Dict]:
        """
        按 DOI 查询 OA 状态（核心方法）

        Args:
            doi: DOI 字符串（如 '10.1038/nature12373'）
            **kwargs:
                email: 邮箱（默认读 UNPAYWALL_EMAIL 环境变量）
                proxy: 代理地址

        Returns:
            完整 DOI Object，失败返回 None
        """
        email = self._get_email(**kwargs)
        if not email:
            return None

        # DOI 需 URL 编码（但 DOI 本身通常安全）
        clean_doi = doi.strip().lower()
        url = f"{self.BASE_URL}/{urllib.parse.quote(clean_doi)}?email={urllib.parse.quote(email)}"

        raw = _http_get(url, timeout=20, proxy=kwargs.get('proxy'))
        if not raw:
            return None

        try:
            import json
            text = raw.decode('utf-8') if isinstance(raw, bytes) else raw
            return json.loads(text)
        except (json.JSONDecodeError, ValueError):
            return None

    def search(self, query: str, max_results: int = 10, **kwargs) -> Optional[List[SearchResult]]:
        """
        标题搜索 OA 文章

        Args:
            query: 搜索文本（空格分隔 AND，支持 "短语"/OR/-取反）
            max_results: 最大结果数（每页 50，自动分页）
            **kwargs:
                email: 邮箱
                is_oa: True 仅 OA / False 仅非 OA / None 不限
                proxy: 代理地址
        """
        email = self._get_email(**kwargs)
        if not email:
            return None

        # 计算分页（每页 50）
        per_page = 50
        pages_needed = max(1, (int(max_results) + per_page - 1) // per_page)
        results: List[SearchResult] = []

        for page in range(1, pages_needed + 1):
            params_dict: Dict[str, str] = {
                'query': query,
                'email': email,
                'page': str(page),
            }
            if kwargs.get('is_oa') is not None:
                params_dict['is_oa'] = 'true' if kwargs['is_oa'] else 'false'

            params = urllib.parse.urlencode(params_dict)
            url = f"{self.BASE_URL}/search?{params}"

            raw = _http_get(url, timeout=20, proxy=kwargs.get('proxy'))
            if not raw:
                break

            try:
                import json
                text = raw.decode('utf-8') if isinstance(raw, bytes) else raw
                data = json.loads(text)
            except (json.JSONDecodeError, ValueError):
                break

            items = data.get('results', []) or []
            if not items:
                break

            for item in items[:max_results - len(results)]:
                doi_obj = item.get('response', {}) or {}
                score = item.get('score', 0.0) or 0.0

                result = self._parse_doi_object(doi_obj, score)
                if result:
                    results.append(result)

            if len(results) >= max_results:
                break

        return results if results else None

    def _parse_doi_object(self, doi_obj: Dict, score: float = 0.0) -> Optional[SearchResult]:
        """解析 DOI Object 为 SearchResult"""
        if not doi_obj:
            return None

        title = doi_obj.get('title', '') or ''
        doi = doi_obj.get('doi', '') or ''
        doi_url = doi_obj.get('doi_url', '') or f"https://doi.org/{doi}"

        # 最佳 OA 位置
        best_oa = doi_obj.get('best_oa_location') or {}
        pdf_url = best_oa.get('url_for_pdf', '') or ''
        landing_url = best_oa.get('url_for_landing_page', '') or ''
        oa_url = pdf_url or landing_url or doi_url

        # OA 状态
        is_oa = doi_obj.get('is_oa', False)
        oa_status = doi_obj.get('oa_status', 'closed') or 'closed'
        version = best_oa.get('version', '') or ''
        license_str = best_oa.get('license', '') or ''
        host_type = best_oa.get('host_type', '') or ''

        # 元数据
        year = doi_obj.get('year')
        pub_date = str(year) if year else ''
        journal = doi_obj.get('journal_name', '') or ''
        publisher = doi_obj.get('publisher', '') or ''
        genre = doi_obj.get('genre', '') or ''

        # 作者
        authors_list = doi_obj.get('z_authors') or []
        author_names = []
        for a in authors_list:
            name = a.get('raw_author_name', '') or ''
            if name:
                author_names.append(name)
        author_str = '; '.join(author_names[:10])
        if len(author_names) > 10:
            author_str += f' et al. ({len(author_names)} authors)'

        # 构建内容片段
        content_parts = []
        if is_oa:
            content_parts.append(f"[OA Status] {oa_status}")
        else:
            content_parts.append("[OA Status] closed (no OA copy)")
        if version:
            content_parts.append(f"[Version] {version}")
        if license_str:
            content_parts.append(f"[License] {license_str}")
        if host_type:
            content_parts.append(f"[Host] {host_type}")
        if journal:
            content_parts.append(f"[Journal] {journal}")
        if publisher:
            content_parts.append(f"[Publisher] {publisher}")
        if genre:
            content_parts.append(f"[Type] {genre}")
        if pdf_url:
            content_parts.append(f"[PDF] {pdf_url}")
        if landing_url and landing_url != pdf_url:
            content_parts.append(f"[Landing] {landing_url}")
        content = '\n'.join(content_parts)

        # 评分：OA 优先，publishedVersion > acceptedVersion > submittedVersion
        version_score = {'publishedVersion': 0.4, 'acceptedVersion': 0.3, 'submittedVersion': 0.2}.get(version, 0.1)
        oa_score = 0.4 if is_oa else 0.0
        final_score = min(oa_score + version_score + min(float(score) / 100.0, 0.2), 1.0)

        return SearchResult(
            title=title,
            url=oa_url,
            content=content,
            source='unpaywall',
            score=final_score,
            published_date=pub_date,
            author=author_str,
            engine='unpaywall',
            raw={
                'doi': doi,
                'doi_url': doi_url,
                'is_oa': is_oa,
                'oa_status': oa_status,
                'best_oa_location': best_oa,
                'all_oa_locations': doi_obj.get('oa_locations', []) or [],
                'pdf_url': pdf_url,
                'landing_url': landing_url,
                'version': version,
                'license': license_str,
                'journal': journal,
            },
        )

    def resolve_pdf_url(self, doi: str, **kwargs) -> Optional[Dict]:
        """
        高频场景：已知 DOI，求 OA PDF URL

        Args:
            doi: DOI 字符串

        Returns:
            {
                'pdf_url': str|None,
                'landing_url': str|None,
                'oa_status': str,
                'version': str,
                'license': str,
                'is_oa': bool,
            }
        """
        doi_obj = self.search_by_doi(doi, **kwargs)
        if not doi_obj:
            return None

        best_oa = doi_obj.get('best_oa_location') or {}
        return {
            'pdf_url': best_oa.get('url_for_pdf') or None,
            'landing_url': best_oa.get('url_for_landing_page') or None,
            'oa_status': doi_obj.get('oa_status', 'closed'),
            'version': best_oa.get('version', ''),
            'license': best_oa.get('license', ''),
            'is_oa': doi_obj.get('is_oa', False),
            'all_pdf_urls': [
                loc.get('url_for_pdf') for loc in (doi_obj.get('oa_locations') or [])
                if loc.get('url_for_pdf')
            ],
        }
```

**关键实现要点**：
1. **email 必需**：`_get_email()` 优先读 kwargs，其次环境变量 `UNPAYWALL_EMAIL`，最后降级默认值（生产环境必须配置真实 email）
2. **DOI 小写化**：官方 schema 要求 doi 字段总是小写
3. **best_oa_location 优先**：直接取 `url_for_pdf`，无需遍历 oa_locations
4. **resolve_pdf_url**：高频场景的便捷方法（已知 DOI 求 PDF URL）
5. **search 分页**：每页 50，自动多页拉取

### 4.1 Semantic Scholar 引用图谱 API（核心）

**官方数据规模（2026-08）**：
- **214M 论文**（Papers）
- **2.49B 引用**（Citations）

> "Most Semantic Scholar endpoints are available to the public without authentication, but they are rate-limited to 1000 requests per second shared among all unauthenticated users."
> "The introductory rate limit for an API key is 1 RPS on all endpoints."

**注意**：v1 报告中「100 req/5min」已过时，官方 2026 数据为「1000 req/s 共享（无 Key）」+「1 RPS（有 Key）」。但实际 429 仍可能因共享池竞争触发，建议配置 Key。

**API Key**：header `x-api-key`（大小写敏感）

**Paper ID 支持格式**：

- `MAG:3015453090`（MAG ID，已停服但历史数据）
- `DBLP:conf/acl/LoWNKW20`
- `ACL:2020.acl-main.447`
- `CorpusId:215416146`

### 4.2 引用图谱核心端点

#### 端点 1：论文详情（含 references/citations 嵌套）

- OA：`isOpenAccess,openAccessPdf`
- **引用列表**：`references`（默认返回 paperId+title）

- BibTeX：`citationStyles.bibtex`

### 4.3 引用意图（intents）— S2 独有能力

`intents` 字段是 Semantic Scholar **独有**的引用意图标注，值为字符串数组：

| intent 值 | 含义 | 用途 |
|-----------|------|------|
| `methodology` | 方法引用 | 论文使用了被引论文的方法 |
| `background` | 背景引用 | 引用作为相关工作背景 |
| `result` | 结果引用 | 引用被引论文的结果 |

**应用场景**：
- 综述写作：筛选 `background` 引用构建脉络
- 方法对比：筛选 `methodology` 引用对比方法
- 结果验证：筛选 `result` 引用验证结论

### 4.4 influential citations — 高价值引用筛选

`isInfluential: true` 表示此引用被 S2 判定为「影响力引用」（基于引用上下文长度、位置、引用意图等启发式）。

**应用场景**：
- 论文质量评估：influentialCitationCount 比 citationCount 更能反映真实影响力
- 引用图谱精简：仅保留 influential 边，减少图谱噪声

### 4.5 Connected Papers 与 Inciteful 的真相

#### Connected Papers

**官方确认（Semantic Scholar API Overview 页面原文）**：
> "Eddie Smolyansky Co-founder, Connected Papers: Since day 1 Connected Papers has been built on top of the Semantic Scholar Open Corpus and APIs, and heavily relies on them to provide paper discovery and search capabilities to its users."

**结论**：Connected Papers **完全基于 Semantic Scholar API 构建**，其共引关系图谱算法可通过 S2 references/citations 端点 + 余弦相似度复现。无官方 API，但可自建。

#### Inciteful

**官方数据（inciteful.xyz 首页原文）**：
- 240M+ 学术论文
- 2B+ 引用索引
- 100% 免费使用
- "Built on open data"
- 使用 link prediction 算法（类似社交网络好友推荐）发现相似论文

**结论**：Inciteful 基于 OpenAlex + Semantic Scholar 开放数据，算法可复现。其核心思路：
1. 以种子论文为中心构建引用网络
2. 用 link prediction（共引/共引相似度）发现相关论文
3. 按网络中心性排序重要论文
4. 按相似度排序相关论文

            include_references: 是否包含参考文献
            include_citations: 是否包含引用此文的文章
            include_intents: 是否包含引用意图（methodology/background/result）
            include_influential: 是否包含 influential 标记
            ref_limit: 参考文献数上限
            cit_limit: 引用此文数上限

        Returns:
            完整论文对象（含 references/citations 嵌套数组）
        """
        # 构建字段列表
        fields = [
            "title", "abstract", "year", "venue", "url",
            "citationCount", "influentialCitationCount", "referenceCount",
            "isOpenAccess", "openAccessPdf", "tldr",
            "authors.name", "authors.affiliations",
            "fieldsOfStudy", "s2FieldsOfStudy",
            "citationStyles.bibtex",
            "externalIds",
        ]

        if include_references:
            ref_fields = ["references.paperId", "references.title", "references.year",
                          "references.citationCount", "references.authors.name"]
            if include_intents:
                ref_fields.append("references.intents")
            if include_influential:
                ref_fields.append("references.isInfluential")
            fields.extend(ref_fields)

        if include_citations:
            cit_fields = ["citations.paperId", "citations.title", "citations.year",
                          "citations.citationCount", "citations.authors.name"]
            if include_intents:
                cit_fields.append("citations.intents")
            if include_influential:
                cit_fields.append("citations.isInfluential")
            fields.extend(cit_fields)

        fields_str = ",".join(fields)
        url = f"{self.PAPER_URL}/{urllib.parse.quote(paper_id)}?fields={fields_str}"

        headers = self._get_headers(**kwargs)
        raw = _http_get(url, headers=headers, timeout=30, proxy=kwargs.get('proxy'))
        if not raw:
            return None

        try:
            text = raw.decode('utf-8') if isinstance(raw, bytes) else raw
            data = json.loads(text)
        except (json.JSONDecodeError, ValueError):
            return None

        # 截断 references/citations 到指定 limit
        if include_references and 'references' in data:
            data['references'] = data['references'][:ref_limit]
        if include_citations and 'citations' in data:
            data['citations'] = data['citations'][:cit_limit]

        return data

    def get_references(
        self,
        paper_id: str,
        fields: str = "title,year,citationCount,abstract",
        limit: int = 100,

    def batch_papers(
        self,
        paper_ids: List[str],
        fields: str = "title,year,citationCount,influentialCitationCount,tldr,abstract",
        **kwargs,
    ) -> Optional[List[Dict]]:
        """
        批量查询论文（一次最多 500 个）

        Args:
            paper_ids: 论文 ID 列表（≤500）
            fields: 返回字段

        Returns:
            论文对象列表（顺序与输入一致，不存在的返回 null）
        """
        if len(paper_ids) > 500:
            # 分批处理
            all_results: List[Dict] = []
            for i in range(0, len(paper_ids), 500):
                batch = paper_ids[i:i+500]
                batch_result = self.batch_papers(batch, fields, **kwargs)
                if batch_result:
                    all_results.extend(batch_result)
            return all_results if all_results else None

        params = urllib.parse.urlencode({'fields': fields})
        url = f"{self.BATCH_URL}?{params}"

        headers = self._get_headers(**kwargs)
        headers['Content-Type'] = 'application/json'

        body = json.dumps({"ids": paper_ids}).encode('utf-8')

        # 注意：batch 是 POST，需扩展 _http_get 支持 POST + body
        # 这里假设 _http_get 有 _http_post 对应方法
        from .fallback import _http_post  # 假设有此函数
        raw = _http_post(url, body=body, headers=headers, timeout=30, proxy=kwargs.get('proxy'))
        if not raw:
            return None

        try:
            text = raw.decode('utf-8') if isinstance(raw, bytes) else raw
            return json.loads(text)
        except (json.JSONDecodeError, ValueError):
            return None

    def build_citation_graph(
        self,
        seed_paper_id: str,
        depth: int = 1,
        max_nodes: int = 50,
        include_intents: bool = True,
        **kwargs,
    ) -> Optional[Dict]:
        """
        构建以种子论文为中心的引用图谱（Inciteful 风格）

        Args:
            seed_paper_id: 种子论文 ID
            depth: 图谱深度（1=直接引用，2=二度引用）
            max_nodes: 最大节点数
            include_intents: 是否包含引用意图

        Returns:
            {
                'nodes': [{'paperId': ..., 'title': ..., 'year': ..., 'citationCount': ...}],
                'edges': [{'source': ..., 'target': ..., 'intents': [...], 'isInfluential': bool}],
                'seed': seed_paper_id,
                'stats': {'total_nodes': int, 'total_edges': int, 'intents_distribution': {...}}
            }
        """
        nodes: Dict[str, Dict] = {}
        edges: List[Dict] = []
        intents_count: Dict[str, int] = {}

        # 第 0 层：种子论文
        seed_data = self.get_paper_with_graph(
            seed_paper_id,
            include_references=True,
            include_citations=True,
            include_intents=include_intents,
            include_influential=True,
            ref_limit=max_nodes // 2,
            cit_limit=max_nodes // 2,
            **kwargs,
        )
        if not seed_data:
            return None

        seed_paper_id_actual = seed_data.get('paperId', seed_paper_id)
        nodes[seed_paper_id_actual] = {
            'paperId': seed_paper_id_actual,
            'title': seed_data.get('title', ''),
            'year': seed_data.get('year'),
            'citationCount': seed_data.get('citationCount', 0),
            'venue': seed_data.get('venue', ''),
            'is_seed': True,
        }

        # 处理 references（种子引用的论文）
        for ref in seed_data.get('references', []) or []:
            ref_paper = ref.get('citedPaper') or ref  # 兼容两种格式
            pid = ref_paper.get('paperId')
            if not pid:
                continue
            if pid not in nodes and len(nodes) < max_nodes:
                nodes[pid] = {
                    'paperId': pid,
                    'title': ref_paper.get('title', ''),
                    'year': ref_paper.get('year'),
                    'citationCount': ref_paper.get('citationCount', 0),
                    'venue': ref_paper.get('venue', ''),
                    'is_seed': False,
                }
            # 边：seed → reference
            intents = ref.get('intents', []) or []
            is_influential = ref.get('isInfluential', False)
            edges.append({
                'source': seed_paper_id_actual,
                'target': pid,
                'type': 'reference',
                'intents': intents,
                'isInfluential': is_influential,
            })
            for intent in intents:
                intents_count[intent] = intents_count.get(intent, 0) + 1

        # 处理 citations（引用种子的论文）
        for cit in seed_data.get('citations', []) or []:
            cit_paper = cit.get('citingPaper') or cit
            pid = cit_paper.get('paperId')
            if not pid:
                continue
            if pid not in nodes and len(nodes) < max_nodes:
                nodes[pid] = {
                    'paperId': pid,
                    'title': cit_paper.get('title', ''),
                    'year': cit_paper.get('year'),
                    'citationCount': cit_paper.get('citationCount', 0),
                    'venue': cit_paper.get('venue', ''),
                    'is_seed': False,
                }
            # 边：citation → seed
            intents = cit.get('intents', []) or []
            is_influential = cit.get('isInfluential', False)
            edges.append({
                'source': pid,
                'target': seed_paper_id_actual,
                'type': 'citation',
                'intents': intents,
                'isInfluential': is_influential,
            })
            for intent in intents:
                intents_count[intent] = intents_count.get(intent, 0) + 1

        # depth >= 2：对每个节点递归（简化版，实际需 BFS + 去重）
        if depth >= 2 and len(nodes) < max_nodes:
            # 此处省略 BFS 扩展逻辑，实际实现需控制请求量
            pass

        return {
            'nodes': list(nodes.values()),
            'edges': edges,
            'seed': seed_paper_id_actual,
            'stats': {
                'total_nodes': len(nodes),
                'total_edges': len(edges),
                'intents_distribution': intents_count,
            },
        }

def render_citation_graph_mermaid(graph_data: Dict) -> str:
    """
    将 CitationGraphEngine.build_citation_graph() 结果渲染为 Mermaid 图

    输出可嵌入 Markdown 报告的 Mermaid 代码块
    """
    nodes = graph_data.get('nodes', [])
    edges = graph_data.get('edges', [])
    seed = graph_data.get('seed', '')

    if not nodes:
        return "```mermaid\ngraph TD\n```"

    lines = ["```mermaid", "graph TD"]

    # 节点（用短 ID 避免 Mermaid 解析问题）
    id_map = {}
    for i, node in enumerate(nodes):
        short_id = f"P{i}"
        pid = node['paperId']
        id_map[pid] = short_id
        title = (node.get('title', '') or 'Untitled')[:30]
        year = node.get('year', '')
        cc = node.get('citationCount', 0)
        is_seed = node.get('is_seed', False)
        # 种子节点用粗框
        style = ':::seed' if is_seed else ''
        lines.append(f'    {short_id}["{title} ({year})<br/>cited:{cc}"]{style}')

    # 边
    for edge in edges:
        src = id_map.get(edge['source'])
        tgt = id_map.get(edge['target'])
        if not src or not tgt:
            continue
        intents = edge.get('intents', [])
        is_inf = edge.get('isInfluential', False)
        # influential 用粗线
        arrow = '==>' if is_inf else '-->'
        label = ','.join(intents) if intents else ''
        if label:
            lines.append(f'    {src} {arrow}|{label}| {tgt}')
        else:
            lines.append(f'    {src} {arrow} {tgt}')

    # 样式定义
    lines.append("    classDef seed fill:#f9f,stroke:#333,stroke-width:2px")
    lines.append("```")
    return '\n'.join(lines)


def render_intents_distribution(stats: Dict) -> str:
    """渲染引用意图分布表"""
    dist = stats.get('intents_distribution', {})
    if not dist:
        return ""
    total = sum(dist.values()) or 1
    lines = ["### 引用意图分布", "", "| 意图 | 数量 | 占比 |", "|------|------|------|"]
    for intent in ['methodology', 'background', 'result']:
        count = dist.get(intent, 0)
        pct = count / total * 100
        lines.append(f"| {intent} | {count} | {pct:.1f}% |")
    lines.append(f"| **总计** | **{total}** | **100%** |")
    return '\n'.join(lines)

- 🔴 **法律风险高**：知网有维权先例（翟天临事件后加强版权保护）

**已知爬虫项目**：
- `ppho99/CNKI-download`：Python3 知网高级检索 + 文献信息/下载/摘要爬取
- 各类社区爬虫（关键词共现网络构建等）

**评估**：🔴 **不推荐集成**。法律风险大于收益，且爬虫稳定性差。

### 6.3 万方数据

**现状**：
- ⚠️ 有「万方科技文献学术搜索接口服务」，**企业付费**
- ❌ 无免费开放 API
- 政府采购合同可见（企业级）

**评估**：🔴 **无免费方案**。元数据可部分用 Crossref/OpenAlex 替代（有 DOI 的中文论文）。

### 6.4 维普资讯

**现状**：
- ❌ 无公开免费 API
- 数据量中等（中文期刊全文）

**评估**：🔴 **同知网/万方，无免费方案**。

### 6.5 百度学术

**现状**：
- ❌ 无官方 API
- ⚠️ 反爬中等（弱于知网，强于 Google Scholar）
- 聚合多源中英文学术资源

**评估**：🟡 **不作为主数据源**。爬虫可行性略高但不稳定，发现层可用 OpenAlex 中文期刊元数据替代。

### 6.6 中文文献法律风险汇总

| 方案 | 法律风险 | 技术可行性 | 推荐度 | 说明 |
|------|---------|-----------|--------|------|
| 知网爬虫 | 🔴 高 | ⚠️ 低（反爬强） | ⭐ | 违反 ToS，有维权先例 |
| 万方爬虫 | 🔴 高 | ⚠️ 低 | ⭐ | 同上 |
| 维普爬虫 | 🔴 高 | ⚠️ 低 | ⭐ | 同上 |
| 百度学术爬虫 | 🟡 中 | 🟡 中 | ⭐⭐ | 违反 ToS，无诉讼先例 |
| ChinaXiv 爬虫 | 🟢 低 | 🟡 中 | ⭐⭐⭐ | CC BY 内容，但无官方 API |
| Google Scholar 爬虫 | 🟡 中 | ⚠️ 低（CAPTCHA） | ⭐⭐ | 违反 ToS，需代理 |
| **OpenAlex 中文期刊元数据** | 🟢 低 | ✅ 高 | ⭐⭐⭐⭐ | 已收录部分中文期刊，持续增长 |
| **Crossref 中文 DOI** | 🟢 低 | ✅ 高 | ⭐⭐⭐⭐ | 有 DOI 的中文论文 |
| **Unpaywall 中文 OA** | 🟢 低 | ✅ 高 | ⭐⭐⭐⭐ | 有 DOI 的中文 OA 论文 |

### 6.7 中文文献可行替代路径（推荐方案）

```
中文文献需求
  ↓
Phase 1: 元数据发现（免费 + 合法）
  ├─ OpenAlex（filter=language:zh，已收录部分中文期刊）
  ├─ Crossref（有 DOI 的中文论文）
  └─ Semantic Scholar（部分中文论文有 paperId）
  ↓
Phase 2: 全文获取（合法 OA 优先）
  ├─ Unpaywall（有 DOI 的中文 OA 论文 → PDF URL）
  ├─ ChinaXiv.org（人工检索，预印本 CC BY）
  └─ 机构图书馆代理（校园网 VPN，合法）
  ↓
Phase 3: 报告标注
  └─ 「中文文献需人工辅助：元数据来自 OpenAlex，全文请访问 ChinaXiv.org 或机构图书馆」
```

**核心结论**：**无免费程序化中文文献全文方案**。元数据用 OpenAlex + Crossref + Unpaywall，全文走人工 + 机构账号。

# scripts/report.py（新增函数）

from .engines.academic_engines import CitationGraphEngine


def add_citation_graph_section(
    report_lines: List[str],
    seed_paper_id: str,
    s2_api_key: Optional[str] = None,
) -> None:
    """
    在报告中追加引用图谱章节

    Args:
        report_lines: 报告行列表（追加写入）
        seed_paper_id: 种子论文 ID（arXiv:xxx / DOI:xxx / paperId）
        s2_api_key: 可选 S2 API Key
    """

    graph = engine.build_citation_graph(
        seed_paper_id,
        depth=1,
        max_nodes=30,
        include_intents=True,
        api_key=s2_api_key,
    )

    if not graph:
        report_lines.append("\n## 引用图谱\n\n*引用图谱获取失败*\n")

    report_lines.append("\n## 引用图谱\n")

    # 统计信息
    stats = graph.get('stats', {})
    report_lines.append(
        f"以种子论文为中心构建引用网络："
        f"{stats.get('total_nodes', 0)} 篇论文，"
        f"{stats.get('total_edges', 0)} 条引用关系。\n"
    )

    # 引用意图分布
    intents_md = render_intents_distribution(stats)
    if intents_md:
        report_lines.append(intents_md)
        report_lines.append("")

    # Mermaid 图
    mermaid_graph = render_citation_graph_mermaid(graph)
    report_lines.append("### 引用关系图（Mermaid）")
    report_lines.append("")
    report_lines.append(mermaid_graph)
    report_lines.append("")

    # Top 引用论文列表
    nodes = sorted(

        key=lambda n: n.get('citationCount', 0),

### 7.5 plan.py 学术意图识别（调度新引擎）

```python
# scripts/plan.py（学术意图识别增强）

def detect_academic_intent(query: str) -> Dict[str, bool]:
    """
    检测查询中的学术意图，决定调度哪些引擎

    Returns:
        {
            'needs_fulltext': bool,      # 需要 ArxivFulltextEngine + UnpaywallEngine
            'needs_citation_graph': bool, # 需要 CitationGraphEngine
            'needs_latex': bool,          # 需要 ArxivFulltextEngine.fetch_latex
            'needs_chinese': bool,        # 中文文献（标注人工辅助）
        }
    """
    query_lower = query.lower()
    return {
        'needs_fulltext': any(kw in query_lower for kw in [
            '全文', 'fulltext', 'full text', 'pdf', '下载', 'download',
            '原文', 'original text', '完整文本',
        ]),
        'needs_citation_graph': any(kw in query_lower for kw in [
            '引用', 'citation', 'reference', '参考文献', '引用图谱',
            'citation graph', 'related papers', '相关论文', '综述', 'review',
        ]),
        'needs_latex': any(kw in query_lower for kw in [
            'latex', '公式', 'formula', '推导', 'derivation', '源码', 'source',
        ]),
        'needs_chinese': any(kw in query for kw in [
            '中文', '知网', '万方', '维普', '百度学术', '中国',
        ]) or '\u4e00' <= query[0] <= '\u9fff' if query else False,
    }


def schedule_academic_engines(intent: Dict[str, bool]) -> List[str]:
    """根据意图返回引擎调度顺序"""
    engines = ['openalex', 'semantic-scholar']  # 元数据基础

    if intent['needs_fulltext']:
        engines = ['unpaywall', 'arxiv-fulltext'] + engines
    if intent['needs_citation_graph']:
        engines.append('s2-citation-graph')
    if intent['needs_chinese']:
        # 中文文献无程序化方案，标注人工辅助
        engines.append('openalex')  # OpenAlex 中文期刊元数据

    return engines
```
